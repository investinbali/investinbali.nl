# Werken aan Invest in Bali

## Rollen van systemen

GitHub is de bron voor websitecode. Google Drive is de bron voor documenten. Vercel is de hostinglaag. Een lokale map is alleen een tijdelijke werkplek om code te wijzigen en te testen.

## Regels voor commits

- Commit kleine, logische wijzigingen.
- Gebruik duidelijke commitberichten.
- Commit geen Drive-documenten, exports, ZIP-bestanden, spreadsheets, screenshots of secrets.
- Controleer voor elke push met `git status` wat er meegaat.

## Aanbevolen volgorde

1. Haal de laatste versie op met `git pull`.
2. Pas websitecode aan.
3. Test lokaal of visueel in de browser.
4. Controleer `git status`.
5. Commit de wijziging.
6. Push naar `main`.
7. Controleer de Vercel deployment en live site.
